# Help Nearby

Help Nearby is a Singapore non-profit pilot that connects residents who need simple digital assistance with trusted volunteers who have 30, 60, or 120 minutes to spare nearby.

AI agents support development, request triage, and matching suggestions. Every pilot match remains human-reviewed, non-emergency, free, and based in familiar common areas.

Website: <https://helpnearby-sg.github.io/>

Contact: <help.nearbysg@gmail.com>

## Run locally

```bash
npm install
npm run dev
```
