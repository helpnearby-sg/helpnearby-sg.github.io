# Help Nearby

Help Nearby is a non-profit pilot concept that connects residents who need
simple digital assistance with trusted volunteers who have 30, 60, or 120
minutes to spare nearby.

The first pilot focuses on digital guidance in familiar common areas. It does
not support emergencies, payments, banking, passwords, medical care, transport,
or private-home visits.

## Website

The public prototype is deployed through GitHub Pages:

<https://whitmanz.github.io/help-nearby/>

The forms currently demonstrate the intended experience and do not store or
send responses.

## Local preview

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

To verify the static GitHub Pages build:

```bash
npm run build:pages
```

## Current pilot boundaries

- Free, non-emergency digital assistance
- Volunteers aged 18 and above
- Human review before any match
- Common-area meetings first
- No guaranteed fulfilment or automatic dispatch
