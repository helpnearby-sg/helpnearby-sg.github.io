# Help Nearby

Help Nearby is a Singapore non-profit pilot that turns 碎片时间 into community support. It connects residents who need simple digital guidance with trusted volunteers who have 10, 20, 30, or 60 minutes to help by call or nearby.

AI agents support development, request triage, and matching suggestions. Every pilot match remains human-reviewed, non-emergency, and free; in-person sessions use familiar common areas.

Website: <https://helpnearby-sg.github.io/>

Contact: <help.nearbysg@gmail.com>

## Run locally

```bash
npm install
npm run dev
```
